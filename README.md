# L-isa_Reaper_Snapshot_sync
Reaper markers trigger L-isa controller snapshots
This script bypasses reapers built in osc functions and uses python to directly send osc on the os level.

INSTALL
-------
* import script as reaper action
* create toolbar button referring to this action.

USAGE
-----
name markers "LISA : 1"
singleclick to turn sync on and off
Doubleclick toolbarbutton to set for L-isa ip and port

ROADMAP
-------
* sync dlive snapshots
